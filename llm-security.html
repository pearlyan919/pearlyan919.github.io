LLM Jailbreak & Security Evaluation

Independent Research · 2026–Present

Overview

I study jailbreak robustness and cross-model transfer using reproducible GCG-based adversarial evaluation, with an emphasis on metrics that reflect meaningful security behavior rather than surface-level refusal alone.

Key Results

10/10 vs. 1/10

Across 10 AdvBench harmful behaviors, GCG succeeded on 10/10 tested targets for Llama-3.2-3B-Instruct, compared with 1/10 for Llama-2-7B-Chat under the same controlled evaluation setting.

100% vs. ~30%

Cross-model transfer was strongly asymmetric: suffixes generated on Gemma-2 transferred to the tested Llama models at 100%, while transfer from the tested Llama models to Gemma-2 was only about 30%.

These results are from the controlled experiments and configurations documented in the project repository.

Methods

  • GCG jailbreak evaluation
  • Cross-model transfer analysis
  • Token-level suffix truncation
  • Output-level security auditing
  • Reproducible experiment pipelines and artifacts
